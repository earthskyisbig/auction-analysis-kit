# 수익 계산 — 8대 필수비용

경매 수익 분석 시 반드시 아래 8개를 전부 반영한다. **해당 없어도 "0원"으로 명시**한다.

| # | 항목 | 산정 기준 |
|---|------|-----------|
| ① | 취득세 | 주택 6억↓ 1.1% / 6~9억 1.1~3.3% / 9억↑ 3.3%. **다주택·조정지역 중과 시 8~12%** (취득주체 반드시 확인) |
| ② | 법무사비 | 정액 60~70만원 또는 낙찰가 0.5% |
| ③ | 체납관리비 | 관리사무소 확인. **공용부분만 매수인 승계**(전용부분 미승계). 폐문부재 물건은 특히 확인 |
| ④ | 명도비 | 전용평당 10만원 기준 또는 정액. 대항력 임차인은 명도소송(별도·장기) |
| ⑤ | 수리비 | 연식·상태별. **누수/하자 vs 인테리어 이원화** 권장. 1층·구축은 크게 잡을 것 |
| ⑥ | 이자비용 | 대출 시 LTV·기간 반영. 수도권 보수 LTV 50%. 무대출이면 0 |
| ⑦ | 중개보수 | 매도가 요율: 6억↓ 0.4%, 6~9억 0.5% |
| ⑧ | 양도세/종소세 | 개인 단기(1년 미만) 주택 70% / 2년↑ 일반세율+장기공제 / **매매사업자=종합소득세**(단기 중과 회피) |

## 추가 항목
- **인수금액**: 권리분석에서 나온 인수보증금·인수권리 → 취득원가에 가산(필수)
- **건물분 부가세**: 85㎡ 초과 + 매매사업자/법인 취득 시

## 손익 공식
```
총취득원가 = 낙찰가 + ①②③④⑤⑥ + 인수금
세전차익   = 매도가 − 총취득원가 − ⑦중개보수
세후차익   = 세전차익 − ⑧양도세/종소세
세전 ROI   = 세전차익 / 총취득원가
```

## 매매사업자 단기매도 성공 패턴 (검증)
- **비수도권 구축 아파트 + 비조정지역 + 85㎡ 이하** → 단기매도 1순위
- 수리비 이원화(누수/하자 vs 인테리어), 목표 타임라인 4개월(낙찰→가계약→본계약→잔금)
- ⚠️ 서울·수도권은 매도 시세 눌림·경매 경쟁으로 단기매도 메리트 약함 → 낙찰가 관리가 핵심
