# 입지분석 기준 (6축 · 가중치 · 채점)

투자가치·환금성 관점의 고정 가중치. 물건유형별 프로파일은 2차 확장(현재는 해석에서 보정).

## 6축 & 가중치
| 축 | 가중 | 담당 | 핵심 질문 |
|---|---|---|---|
| 🚇 교통 | 25% | 코드 | 전철역이 도보권인가, 노선·환승은 |
| 💼 직주근접 | 20% | 코드 | 주요 업무지구까지 통근이 되나 |
| 🏫 학군 | 20% | 코드+조사 | 초품아·중학군·학원가 |
| 📉 공급물량 | 15% | 에이전트 | 향후 2~3년 입주물량(감점) |
| 🏪 인프라 | 10% | 코드 | 마트·병원·공원·상권 |
| 🚀 호재 | 10% | 에이전트 | GTX·재개발·이전(검증됨) |

## 채점 밴드 (0~100)

### 교통 — 최근접 전철역 도보거리(m)
≤300:100 / ≤500:90 / ≤800:78 / ≤1200:62 / ≤2000:45 / ≤3000:28 / 그이상:12
· 1km 내 역 2개↑(복수노선/환승 근접) → +5

### 직주근접 — 최단 자동차 통근(분)
≤20:100 / ≤30:88 / ≤40:74 / ≤50:60 / ≤60:46 / ≤75:32 / 그이상:18
· 업무지구: 강남·판교·여의도·광화문·구로디지털 중 최솟값

### 학군 — 가중 합성
- 초품아(초등 도보 m, 50%): ≤300:100 / ≤500:85 / ≤800:60 / ≤1200:35 / 그이상:15
- 학원 밀집(1km 내 학원수, 30%): ≥50:100 / ≥25:85 / ≥12:68 / ≥5:50 / ≥1:32 / 0:10
- 중학 접근(중학교 m, 20%): ≤500:100 / ≤1000:75 / ≤1500:50 / 그이상:25

### 인프라 — 1km 내 합산(최대 100)
대형마트 ≥1: +30 / 병원 ≥10:+30·≥5:+22·≥1:+12 / 공원 ≥1:+20 / 편의점 ≥10:+20·≥5:+12·≥1:+6

### 공급물량 (감점축, 에이전트)
적음·없음:90~100 / 보통:55~70 / 대단지 다수(공급폭탄):20~40

### 호재 (에이전트, 검증 필수)
확정(착공·관리처분):85~100 / 추진(예타·지구지정):60~80 / 계획·불확실:40~55 / 없음:30

## 종합
```
종합점수 = Σ(축점수 × 가중치) / 100
등급: S 85+ · A 70+ · B 55+ · C 40+ · D <40
```

## 해석 원칙
- 코드 4축(교통·직주·학군·인프라)은 재현 가능한 수치. 임의 변경 금지.
- 정성 2축(공급·호재)은 **출처·일정 병기**, 미확정 호재는 감점/명시.
- 소형·월세형은 교통·직주 실질 비중↑, 대형·실거주는 학군↑ — 가중치는 고정하되 결론 서술에서 보정.
- 자동차 통근은 평시 추정. 대중교통 통근 중요 시 별도 확인(ODsay 등, 2차 확장).
