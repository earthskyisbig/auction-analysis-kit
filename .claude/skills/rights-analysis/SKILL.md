# ② 권리분석 (rights-analysis)

단일 사건번호 하나를 상세페이지까지 열어 **5개 법원문서를 수집하고 권리관계를 판정**하는 2단계 스킬.
"권리가 불명확하면 수익도 없다" — 수익 계산(③) 전에 반드시 이 단계를 통과해야 한다.

## 무엇을 뽑아내는가

`scripts/analyze_case.py`(저장소 루트 scripts/)가 한 번에:
1. **매각물건명세서** — 최선순위설정(=말소기준), 배당요구종기, 임차인 표(성명·보증금·전입·확정일자·배당요구), 인수주의·특별매각조건
2. **사건상세조회** — 청구금액, 접수·개시일, 담당계
3. **현황조사서** — 점유관계, 임차인 목록
4. **감정평가서요약** — 위치·구조·사용승인일·공법상제한
5. **인근매각물건사례** — 동일 시군구·용도 낙찰가율

## 사용법

```bash
python scripts/analyze_case.py --court 수원지방법원 --case 2025타경55979 -o case.json
# 등기부 PDF가 있으면 정밀 인수금까지: --deungibu ./등기부.pdf
```

## 판정 규칙 (반드시 지킬 것)

- **말소기준권리** = 최선순위 (근)저당·(가)압류·담보가등기·경매개시 중 가장 빠른 것.
  이후 설정 권리는 원칙 소멸, 이전은 인수.
- **임차인 대항력** = 전입신고일 < 말소기준일 이면 대항력 있음 → **보증금 인수 위험**.
  배당요구+확정일자 있으면 배당으로 회수 가능(단 전액 배당 못 받으면 잔액 인수).
- **명세서 "임차인 없음"** 이라도 현황조사서에 전입세대·외국인 등재자가 있으면
  → **전입세대열람으로 교차확인** 안내(불일치 사례 자주 있음).
- **청구금액이 감정가 대비 소액**이면 신청채권자 청구액일 뿐 → 등기부로 총 채무 확인.
- 명세서는 **매각기일 1주 전부터** 공개. 그 전이면 임차인 표가 비어 있을 수 있다(미공개 표기).

## ⚠️ 열람 시점 주의
- 매각물건명세서: 매각기일 1주 전~, 현황조사서·감정평가서: 2주 전~ 조회 가능.
- 그 이전 물건은 권리분석이 불완전 → 리포트에 "명세서 미공개, 재확인 필요" 명시.

## 출력 → 다음 단계
- `case_<사건번호>.json` (원본 문서 + 정리된 report).
- 권리가 "안전(인수 0원)"으로 확인되면 **profit-analysis(③)** 로 진행.
- 인수 위험이 있으면 인수금액을 ③의 취득원가에 반드시 더한다.

## 사이트 함정 (analyze_case.py가 이미 처리함)
- 검색응답은 지연 도착 → 결과 그리드 DOM 출현으로 대기.
- 상세진입 `moveDtlPage(0)` 첫 호출은 씹힘 → 반복 호출.
- 명세서는 별도 브라우저 세션에서 열어야 뜸(window.open 신뢰제스처).
