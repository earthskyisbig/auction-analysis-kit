# ③ 수익성 분석 (profit-analysis)

권리분석(②)으로 인수금이 확정된 물건에 대해, **실거래 시세 + 8대 비용**으로 실제 수익을 계산하는 3단계.

## 순서

### 1. 실거래 시세 확정 (국토부 real-estate MCP)
동일 단지·동일 평형(±3㎡) 최근 3~6개월 실거래로 매도 시세를 잡는다.
- 아파트: `mcp__real-estate__get_apartment_trades(region_code, year_month)`
- 빌라/다세대: `mcp__real-estate__get_villa_trades(...)`
- 지역코드: `mcp__real-estate__get_region_code("○○구 ○○동")` 먼저 호출
- **동일 단지 실거래가 최우선 근거.** 없으면 동일 읍면동·유사 면적·유사 연식으로.
- 층 보정: 1층/최상층은 로열층 대비 -10~15% 반영. 이상치(단일 고가/저가)는 제외.
- 시세는 **보수/중립/낙관 3단계**로 제시.

### 2. 예상 낙찰가 추정
- 인근 동일 용도 평균 매각가율(analyze_case의 인근매각 데이터) 참고.
- 시세 > 감정가면 경쟁 심함 → 낙찰가 높게. 감정가 ≈ 시세면 할인 메리트 작음(최저가 근처만 매력).
- 낙찰가는 **시나리오(예: 최저가/+5%/+10%)로 민감도 표** 제시.

### 3. 8대 필수비용 (전부 명시 — 해당 없어도 "0원")
| # | 항목 | 산정 |
|---|------|------|
| ① | 취득세 | 주택 1.1~3.3%(6/9억 구간), 다주택·규제 중과 시 8~12% (반드시 주체 확인) |
| ② | 법무사비 | 정액 60~70만 or 낙찰가 0.5% |
| ③ | 체납관리비 | 관리사무소 확인(공용부분만 승계). 미확인 시 추정+명시 |
| ④ | 명도비 | 전용평당 10만 기준 or 정액. 대항력 임차인=명도소송 별도 |
| ⑤ | 수리비 | 연식·상태별. 누수/하자 vs 인테리어 이원화 권장 |
| ⑥ | 이자비용 | 대출 시 (LTV·보유기간). 무대출이면 0 |
| ⑦ | 중개보수 | 매도가 요율(6억 이하 0.4%) |
| ⑧ | 양도세/종소세 | 개인 단기(1년 미만) 주택 70% / 매매사업자=종합소득세 / 보유기간·주체별 |
| + | 인수금액 | ②권리분석의 인수보증금(있으면 필수 가산) |
| + | 건물분 부가세 | 85㎡ 초과 + 매매사업자/법인 시 |

### 4. 손익
- 총취득원가 = 낙찰가 + ①~⑦(매도비용 제외분) + 인수금
- 세전차익 = 매도가 − 총취득원가 − 중개보수
- 세후 = 세전 − ⑧
- **결론에 "권장 낙찰상한"**(이 이하로 받아야 수익) 을 반드시 제시.

## 도메인 규칙 (검증됨)
- 매매사업자 단기매도 성공 패턴: **비수도권·비조정지역·85㎡ 이하 구축**이 1순위(세후 ROI 우수).
  서울/수도권은 단기매도 메리트가 상대적으로 약함(매도 시세 눌림·경쟁).
- 감정가 > 실거래 중앙값이면 "경매 할인폭 작음" 경고.

## 출력 → 다음 단계
- 낙찰가 시나리오별 손익표 + 권장 낙찰상한 + 판단(GO/조건부/보류).
- 이후 **report-builder(④)** 로 종합 HTML 보고서 생성.
