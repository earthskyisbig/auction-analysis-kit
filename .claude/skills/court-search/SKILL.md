# ① 법원경매 물건 검색·수집 (court-search)

법원경매정보 사이트에서 조건에 맞는 물건을 **전량** 수집해 CSV로 저장하는 1단계 스킬.

## ⚠️ 핵심 원칙 (이 스킬이 존재하는 이유)

이 사이트는 **UI 페이지버튼을 클릭하는 방식으로는 물건이 대량 누락된다.**
(WebSquare 파이프라인 지연 → 같은 페이지 반복 수집 → 328건 중 113건만 수집된 실제 사례)

→ 반드시 `scripts/collect_api.py`를 써라. 이 스크립트는 검색 API(`searchControllerMain.on`)를
`dma_pageInfo.pageNo`로 직접 페이징(pageSize=40)하고, **수집 건수 == 사이트 totalCnt** 를
검증한다. 미달 시 경고를 낸다.

## 사용법

```bash
# 준비 (최초 1회)
pip install playwright && python -m playwright install chromium

# 예: 수원 권선구 아파트, 59~95㎡, 유찰1~3회, 3억~10억
python .claude/skills/court-search/scripts/collect_api.py \
  --court 수원지방법원 --sido 경기도 --sgg 권선구 \
  --lcl 건물 --mcl 주거용건물 --scl 아파트 \
  --flbd-min 1회 --flbd-max 3 \
  --min-price 300000000 --max-price 1000000000 \
  --area-min 59 --area-max 95 --bid-days 180 -o out.csv
```

## 옵션

| 옵션 | 설명 |
|------|------|
| `--court` | 법원명(드롭다운 표기 그대로). 예: 수원지방법원, 서울남부지방법원, 의정부지방법원 |
| `--sido` / `--sgg` / `--emd` | 시도 / 시군구 / 읍면동 (시군구·읍면동은 사후필터) |
| `--lcl` `--mcl` `--scl` | 용도 대/중/소분류. 기본 건물>주거용건물>아파트. `--scl 다세대주택` 등 |
| `--flbd-min` `--flbd-max` | 유찰 최소/최대 (예: 1회 / 3) |
| `--min-price` `--max-price` | 최저매각가 하한/상한 (원 단위, 서버필터) |
| `--area-min` `--area-max` | 전용면적 하한/상한 (㎡, 서버필터) |
| `--bid-days N` | 입찰기간을 오늘~+N일로 확장 (기본은 사이트 기본 2주). 넓게 보려면 180 권장 |
| `-o` | 출력 CSV |

## 법원-지역 매칭 (자주 쓰는 것)

| 지역 | `--court` 에 넣을 값(드롭다운 표기) |
|------|------|
| 서울 금천/영등포/구로/양천/강서 | `서울남부지방법원` |
| 수원·용인·화성·오산 | `수원지방법원` |
| 성남·하남·광주 | `성남지원` |
| 여주·이천·양평 | `여주지원` |
| 평택·안성 | `평택지원` |
| 안산·광명·시흥 | `안산지원` |
| 안양·과천·군포·의왕 | `안양지원` |
| 양주·의정부·동두천·포천·연천 | `의정부지방법원` |
| 고양·파주 | `고양지원` |
| 남양주·구리·가평 | `남양주지원` |
| 부천·김포 | `부천지원` (인천지법 관할) |

> 사용자가 시군구만 말하고 법원을 모르면, 위 표로 관할 법원을 추정해 알려주고 진행하라.
> **경기도 등 "도(道) 전역"** 요청이면 관할 법원이 여러 개다 → 위 표의 해당 법원들을 **각각 실행**해 CSV를 합쳐라.

### 🔴 지원(支院) 법원명 함정 — 반드시 지킬 것
`--court` 는 드롭다운 **옵션 텍스트와 매칭**되는데, 지원은 **본원명을 붙이면 안 되고 짧은 이름만** 넣어야 한다.
- ✅ `--court 성남지원`, `--court 부천지원`, `--court 고양지원`
- ❌ `--court "수원지방법원 성남지원"` → 옵션에 그런 텍스트가 없어 **매칭 실패**
- ⚠️ **매칭 실패해도 스크립트는 멈추지 않고** 드롭다운 기본값(**서울중앙지방법원**)으로 검색해 버린다.
  → 결과가 엉뚱한 지역(예: 서울 종로)이면 법원명이 안 먹은 것. **필터코드 로그의 `cortOfcCd` 가 법원마다 다른지** 확인하라(같으면 폴백된 것).
- 정확한 옵션 표기가 의심되면, 폼 로드 후 `#mf_wfm_mainFrame_sbx_rletCortOfc` 의 옵션 텍스트를 덤프해 확인.

## 출력 & 다음 단계

- 출력 CSV 컬럼: 사건번호·물건소재지·전용면적·감정가·최저가·저감율·유찰횟수·매각기일
- ⚠️ **최저가는 `notifyMinmaePrice1`** (현재 최저가). 유찰횟수는 저감율로 역산이 더 정확.
- 수집 후: 관심 물건을 골라 **rights-analysis(②)** → **profit-analysis(③)** → **report-builder(④)** 로 진행.
- 결과를 DuckDB에 누적하려면 `auction_listings` 테이블에 적재(선택).

## 트러블슈팅
- "정합성 검증 실패" 경고 → 재실행. 반복되면 `--bid-days`를 줄이거나 법원을 분할.
- 결과 0건 → 입찰기간(기본 2주) 때문일 수 있다. `--bid-days 180`으로 확장.
- 시군구 서버필터는 미적용(사후필터)이라 관할 전체를 받아 거른다. 정상 동작.
