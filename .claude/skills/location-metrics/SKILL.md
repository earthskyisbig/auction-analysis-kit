# ⑤-a 입지 정량지표 (location-metrics)

물건 좌표를 기준으로 **측정 가능한 4개 축을 결정론적으로 계산**하는 코드 스킬.
공급물량·호재(정성 2축)는 **location-analyst 에이전트**가 채운다. (역할 분담: 계산=코드, 판단=에이전트)

## 사전 준비
- `.env`(키트 루트)에 `KAKAO_REST_API_KEY`
- 카카오개발자: REST 키 + **카카오맵/로컬** + **카카오내비(길찾기)** 활성화

## 사용법
```bash
python .claude/skills/location-metrics/scripts/location_metrics.py \
  --complex 양주푸르지오아파트 --address "경기도 양주시 덕계동 852" \
  --label "2025타경72795" -o loc.json
```
- `--complex` 단지명(키워드 지오코딩 우선, 가장 정확) · `--address` 지번(폴백)
- 좌표를 이미 알면 `--lat --lon` 직접 입력 가능

## 6축과 가중치
| 축 | 가중 | 담당 | 측정 |
|---|---|---|---|
| 교통 | 25% | 코드 | 최근접 전철역 도보거리(+복수노선 가점) |
| 직주근접 | 20% | 코드 | 강남·판교·여의도·광화문·구디 중 **최단 자동차분** |
| 학군 | 20% | 코드 | 초품아(초등거리)·학원수(1km)·중학거리 가중 |
| 공급물량 | 15% | **에이전트** | 향후 2~3년 생활권 입주물량(감점축) |
| 인프라 | 10% | 코드 | 1km 마트·병원·공원·편의점 |
| 호재 | 10% | **에이전트** | GTX·재개발·기업이전(일정·출처 검증) |

## 출력
`loc.json` — 각 축 raw 지표 + 점수(0~100) + **코드 4축 소계**(가중합 75%를 100점 재정규화).
공급물량·호재는 `score: null`("에이전트 조사 필요")로 비워둔다.

## 다음 단계
1. 이 스킬로 정량 4축을 낸다.
2. **location-analyst 에이전트**를 호출해 공급물량·호재 2축을 조사·채우고 **6축 종합점수·등급(S/A/B/C/D)** 산출.
3. report-builder(④)가 입지 섹션(레이더+축별 코멘트)으로 표시.

## 채점 기준
`knowledge/03_입지분석_기준.md` 참조. 채점 밴드를 바꾸려면 스크립트의 `score_band` 호출부와 knowledge를 함께 수정.

## 한계 (반드시 고지)
- 자동차 통근은 **평시 기준 추정** — 출퇴근 러시/대중교통과 다름. 대중교통 통근이 중요하면 ODsay 등으로 별도 확인.
- 카카오 `total_count` 기반 개수는 카테고리 분류 편차가 있을 수 있음(참고치).
- 학원수·병원수는 "밀집도" 지표일 뿐 질을 보장하지 않음.
